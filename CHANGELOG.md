# Изменения

Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии - [SemVer](https://semver.org/lang/ru/).
Раздел нужной версии автоматически становится описанием релиза на GitHub.

## [0.1.7] - 2026-11-10

### Исправлено
- У RadminGrid.exe и ярлыка появилась иконка; тот же значок теперь у окон программы.

### Изменено
- Обновления проверяются и скачиваются без настройки: поле токена и ссылки на страницу релизов убраны из окон программы.
- Раздел «О программе» убран; кнопки «Открыть папку программы» и «Создать ярлык на рабочем столе» перенесены в «Оформление».

## [0.1.6] - 2026-11-10

### Добавлено
- Кнопка «Создать ярлык на рабочем столе» в разделе «О программе».

### Изменено
- Рефакторинг: MainForm разбит на файлы по назначению (обновления, телефонная книга, подключение, элементы оформления), меню вынесено в отдельный файл.
- Из текстов интерфейса, исходников и документации убраны типографские символы.

## [0.1.5] - 2026-09-29

### Добавлено
- Токен GitHub для обновлений встраивается в программу при сборке - проверка и установка обновлений из приватного репозитория работают без настройки.
- Свой токен в настройках (Настройки → Обновления) по-прежнему можно указать - он важнее встроенного, если тот истёк или отозван.

## [0.1.4] - 2026-09-29

### Добавлено
- Обновления через GitHub Releases: проверка при запуске и по кнопке «Проверить сейчас» (Настройки → Обновления).
- Загрузка обновления с проверкой SHA-256, имени и версии сборки; установка без прав администратора и перезапуск.
- Откат: если новый файл не удалось поставить на место, прежняя версия остаётся.
- «Пропустить версию», предварительные версии по желанию, токен GitHub для приватного репозитория (хранится в DPAPI).
- Версия программы в заголовке журнала и в разделе «О программе» берётся из сборки.
- Сборка на GitHub Actions и автоматический выпуск релиза по тегу `v*`.

## [0.1.0]

- Первая версия: массовое подключение к узлам Radmin Viewer, автоввод логина и пароля, сетка окон, вкладки, HUD, чтение номера смены (OCR).
